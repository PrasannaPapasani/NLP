🧠 NLP Practice with spaCy

This repository is a practice workspace for Natural Language Processing (NLP) using spaCy.
It is designed for learning core NLP concepts through hands-on experiments and small examples rather than building a single large application.

📌 Purpose of This Repository

Practice NLP concepts using spaCy

Understand how text is processed and analyzed

Experiment with different spaCy pipelines and features

Build a strong foundation for real-world NLP projects
